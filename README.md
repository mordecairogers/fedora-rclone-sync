# Fedora Rclone Sync website

Public informational pages for the owner's personal Google OAuth Desktop client. This repository contains only website assets. It does not run synchronization or receive Google credentials.

Publish the `main` branch, `/ (root)` using GitHub Pages. Keep HTTPS enabled. The expected homepage is `https://mordecairogers.github.io/fedora-rclone-sync/`; the privacy URL is `https://mordecairogers.github.io/fedora-rclone-sync/privacy.html`. These URLs work only after the repository and Pages deployment exist.

To edit: update `index.html`, `privacy.html`, or `style.css`. No build, package installation or JavaScript is needed. Keep the policy consistent with the actual configuration. Never upload vaults, rclone config, OAuth JSON, tokens, local reports, or backups.
